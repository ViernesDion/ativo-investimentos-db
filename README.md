# 🏦 Ativo Investimentos - Base de Dados

Este repositório contém a modelagem e os scripts SQL de uma base de dados relacional desenvolvida para uma consultoria de investimentos, a **Ativo Investimentos**. 

Projeto desenvolvido em grupo para apresentação em congresso universitário no âmbito do curso de Ciência da Computação.

## 🛠️ Tecnologias e Ferramentas
* **SGBD:** PostgreSQL
* **Modelagem Visual:** Figma

## 📌 Visão Geral do Sistema
A estrutura da base de dados foi projetada para gerir:
* **Clientes e Perfis:** Registo de investidores e classificação de perfil (Conservador, Moderado, Arrojado).
* **Ativos Financeiros:** Categorização de investimentos em Renda Fixa, Renda Variável e Fundos, com os respetivos níveis de risco.
* **Carteiras:** Relacionamento entre clientes e as suas posições em diferentes ativos.
* **Projeções:** Cálculo de rentabilidade esperada a curto, médio e longo prazo.
